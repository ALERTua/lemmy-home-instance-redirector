# Changelog

All notable changes to this project are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.1.2]

### Added

- Link to the GitHub repository on the settings page.
- Listing on addons.mozilla.org.

## [0.1.1]

### Changed

- Shorter description of the add-on.
- Link to the GitHub repository as the homepage of the add-on.

## [0.1.0]

### Added

- Redirect of posts, comments, communities and users from any Lemmy or PieFed server to your home Lemmy instance.
- Redirect past the login page of private Lemmy servers and of PieFed servers that hide their content from guests.
- Toolbar button and settings page for the home instance. The settings page opens after the installation.
- No redirect when you come from your home instance, or when the address ends with `#noredirect`.
